# BLAGO

Kaubojski automat. Vrti, gradi selo, pohodi.

## Pokretanje

```bash
npm install
npm run dev
```

Otvori [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Stack

React 19 · Vite · Zustand · Tailwind v4 · Capacitor (Android)

## Skripte

- `npm run build` — produkcijski web
- `npm test` — logika (energija, linije, mreža, pohod)
- `npm run test:e2e` — prolaz kroz igru (Playwright)
